# Portfolio

This folder contains a personal portfolio website.

## Files

- `index.html` – Main webpage for the portfolio.
- `index.css` – Stylesheet for the portfolio page.
- `Prince.pdf` – Portfolio or resume document.
- `prince.png` – Image used on the portfolio page.

## How to use

Open `index.html` in a web browser to view the portfolio site.

## Notes

- Edit `index.html` to update portfolio content.
- Edit `index.css` to change styling.
- Replace `Prince.pdf` and `prince.png` with your own resume/image if needed.
